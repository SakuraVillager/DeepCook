# DeepCook 0.1.3：恢复详情样式

根据最新反馈，恢复 0.1.1 的菜谱详情视觉：用时和原始份量分行、原有正文间距与材料排版、连续步骤、观察提示卡和文字版“放大阅读”按钮。

首页保留 0.1.2 的精选卡片布局和圆角。根据后续反馈，卡片菜名改为 14sp 常规字重，时间和难度改为 12sp，辅助图标缩至 13dp，保持菜名大于辅助信息。分步阅读是独立页面，继续保留此前已完成的阅读排版。

保留最近浏览在转场后记录、重复导航防护、章节定位和返回步骤定位等修复，以及 R8 优化的 Preview 构建。

交付文件：`artifacts/DeepCook-0.1.3-preview.apk` 与 `artifacts/DeepCook-0.1.3-debug.apk`。

0.1.2 的性能对照属于当时版本的历史记录，不作为本次样式恢复后的重新测量结果。
