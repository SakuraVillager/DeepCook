# DeepCook 0.1.4：封面信息与材料列表

- 首页精选封面的底部增加透明至深黑的渐变，左侧显示难度（例如 `3/5`），右侧显示时钟和用时（例如 `75`）；移除图片下方重复的信息行。
- 菜名继续使用 14sp 常规字重，封面信息为 12sp，保留现有卡片圆角和收藏按钮。
- 时间显示省略“分钟”；无障碍描述继续说明单位。难度缺失时显示 `—`，无障碍描述为“难度未标注”。
- 材料列表的行和分隔线放在同一个无额外行间距的容器中，每行上下留 6dp；材料名称和用量对齐，大字体时自然增高。其他详情内容沿用上一版样式。

## 难度数据

`Recipe.difficulty` 与 `RecipeFilter.difficulty` 使用可空整数。有效值为 1–5，1 代表较低难度，5 代表较高难度。内容读取会拒绝范围外的分值。

原演示内容仅标注“简单”和“中等”，按 1 和 3 转换；原“较难”标签的转换规则为 5。未填写的值继续为空。该转换延续原示例的粗略等级，不代表额外的精细评测。内容清单及维护工具统一使用第 2 版菜谱格式，菜谱 ID、收藏与浏览记录不变。

搜索难度菜单提供不限及 `1/5` 至 `5/5`，选择后按分值精确筛选；清除筛选恢复全部菜谱，包括未标注难度的菜谱。

交付 APK：`artifacts/DeepCook-0.1.4-preview.apk`；开发包：`artifacts/DeepCook-0.1.4-debug.apk`。
