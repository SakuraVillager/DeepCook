# 首次引导与饮食偏好（0.5.0）

四页依次为喜好、忌口、下厨习惯和使用目标。暖黄背景、白色细边框选项配原生矢量小饭碗／番茄插画，插画无需联网或图片权限。所有问题均可不填，右上角可直接跳过整个设置，每页也能暂不填写。

## 保存与恢复

- `UserData.foodSetup` 保存已确认的 `profile`、首次引导 `draft`、当前页和完成标记，沿用私有 DataStore JSON。
- 首次填写的选择和页码串行写入草稿；完成／跳过排在同一写入队列末尾，提交当前答案并清理草稿，避免旧草稿覆盖最终保存。
- 系统重建通过 SavedStateHandle 恢复；重新启动从持久化草稿恢复。保存失败保留选择、提示重试，不宣称完成。
- “我的 → 饮食偏好”重用四页问答。编辑只在点击保存时提交，取消和返回不覆盖已保存偏好；不影响首次引导完成标记。
- 过敏／不耐受的 `null` 表示未回答，空集合表示用户明确选择“没有已知项”，非空集合表示已登记食材。普通忌口单独记录；自定义食材可添加，点选中的标签即可移除。
- 未选择任何答案即可进入首页，不自动填写“没有过敏”。已完成或跳过后不重复展示。
- 老版本 JSON 缺少 `foodSetup` 时迁移为已完成，保留收藏、最近浏览和外观／阅读设置。已有安装升级后通过个人页进入编辑，不强制重复引导。
- “恢复默认设置”仍只重置外观与阅读，不删除饮食偏好。

## 推荐范围

- 未填偏好继续展示原有精选；填写后首页显示“合你口味”，按菜系、口味、已知用时、难度与相关目标排序，保留原列表的稳定顺序作为平分规则。
- 已登记的忌口、过敏／不耐受食材及饮食方式用于首页推荐排除；包含已识别辣椒类材料的菜谱不进入“不吃辣”用户的推荐。
- 匹配菜谱材料名及常见别称／调料名称。严格匹配并非过敏原不存在的认证，不宣称安全；有饮食排除要求时不推荐材料为空或材料名为“无”的内容。
- 页面简短提示核对实际食材和调料。没有可靠来源的辣度、分量或营养参数不补造；人数只记录习惯，不自动改变菜谱原始用量。
- 搜索、收藏及最近浏览保留原内容，用户仍可主动查看其他菜谱；首页“查看全部”进入完整搜索。
- 当前为完全本地规则，没有上传用户信息或调用 AI。饮食方式、部分口味与细分菜系按现有材料／文字匹配，后续可增加更完整的内容标签。

## 界面与适配

- 原生 Canvas 绘制厨房小伙伴；选项图标使用同一套 Rounded Material Icons。
- 整行目标／经验选项可点击，经验为单选语义，目标为多选语义；标签至少 48dp 触控高度。
- 进度条四段，前后翻页保留选择并使用轻量横向淡入淡出；第一页面与后续页面保留同宽返回槽位，避免进度条突然移动。
- 内容最大宽度 640dp、居中显示；正文纵向滚动，操作区固定，尊重系统字号、键盘和安全区。
- 首屏等待本地用户数据读取，防止已完成用户看到引导闪现。计时器通知跳转在引导完成后处理。
