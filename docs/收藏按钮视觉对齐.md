# DeepCook 0.1.5：收藏图标视觉对齐

首页卡片原先使用默认 24dp 星标，而菜名为 14sp，默认字体下星标明显偏大；图标按钮自身的内边距也影响可见边缘的对齐。

本次将首页星标改为默认 16dp，随系统字体缩放。只调整图形的位置，默认向右偏移 8dp，让可见右边缘与菜名的左侧留白更接近；大字体下自动减少位移。收藏按钮的点击区域保持 48×48dp。

菜名大小、卡片布局与圆角继续沿用上一版。列表和详情中的收藏按钮保持原样。

交付：`artifacts/DeepCook-0.1.5-preview.apk` 与 `artifacts/DeepCook-0.1.5-debug.apk`。

验证：Debug/Preview 构建、ktlint 与 `git diff --check` 通过；Lint 无错误；收藏同步、取消与撤销的专项 UI 测试通过。已检查默认字体与系统字体缩放 2.0 下的实际截图，以及未收藏和已收藏两种状态。
