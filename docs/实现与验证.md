# DeepCook 0.1.0 实现与验证

日期：2026-10-16。

## 已实现

- Kotlin / Compose / Material 3 单模块 Android 工程，最低 API 26，编译和目标 API 36。
- 找菜、名称与食材搜索、分类/用时/难度联合筛选。
- 完整菜谱、吸顶分段导航、按步骤进入专注阅读、目录与翻步、返回定位和页面重建恢复。
- 收藏持久化、跨页同步、取消后撤销。
- 我的厨房：收藏摘要、最近浏览、完整历史列表；记录去重，最多保留 50 道。
- Mihon 风格设置行、暖黄厨房明暗主题、动态配色、三档字号、步骤图片及前台阅读保持亮屏。
- 最近浏览、收藏和偏好的独立清理与确认；内容、图片授权和开源许可页面。
- 12 道自编示例菜谱、12 张本地配图、图片固定版本来源清单。

本阶段没有接入 AI、语音、计时、做菜会话、账号和云端同步。所有核心浏览功能可离线使用。

## 自动验证

最终执行：

```text
:app:assembleDebug
:app:testDebugUnitTest
:app:lintDebug
:app:connectedDebugAndroidTest
```

- JVM 单元测试：7 项，覆盖多关键词、联合筛选、缺失元数据、收藏顺序、历史去重及上限、序列化与损坏数据。
- Android 模拟器测试：4 项，覆盖搜索到详情/阅读、阅读翻步/目录/重建恢复、收藏/撤销/个人中心同步、外观和阅读设置，以及真实 DataStore 重开与独立清理。
- Kotlin 格式检查：ktlint 1.7.1，依照项目 `.editorconfig`。
- 内容清单检查：12 个唯一菜谱 ID、6 道精选、完整步骤和有效本地封面路径。

Lint 保留 SDK/依赖升级提示：本版依照计划固定 SDK 36 及兼容的稳定依赖组合，较新 Compose、Lifecycle 和 Coil 需要 SDK 37。具体报告随构建生成。

真实 DataStore 持久化在 Android 测试中验证。Windows JVM 的文件覆盖重命名语义与 Android 不同，未用桌面文件系统代替 Android 文件系统验证。

## 实际页面检查

使用 Android 15 / API 35 x86_64 模拟器，调整显示参数检查：

- 约 412dp 与 360dp 手机宽度。
- 900dp 横向窗口：侧边导航、多列网格、紧凑首页头部。
- 浅色、深色，以及外观页中的动态主题预览。
- 系统字体缩放 1.0、1.3 和 2.0；大字体下网格降为单列，设置项自然换行。
- 首页、详情、专注阅读、我的厨房、设置和主题预览。

页面截图位于忽略目录 `artifacts/screenshots`，组合预览为 `preview.png`。
可使用 `tools/capture_emulator.py --serial emulator-5554 --reset-user-data` 在专用模拟器上复现截图场景。
该选项只清理指定模拟器中的 DeepCook 数据；脚本拒绝物理设备序列号。

本次没有覆盖 API 26 真机、API 36 真机、折叠屏铰链和真实厨房环境。模拟器中调整尺寸的检查不等同于各类实体设备测试。
