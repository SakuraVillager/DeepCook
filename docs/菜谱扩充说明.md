## 参数和内容规则

- 名称、材料、步骤均中文展示；原作者署名、可搜索的外文原名保留。
- 原文明确的整道菜参考时间可以收录，支持中文数字与小时换算。不会把分步骤时间相加充当总时间；无法确定单一总时长时保留为空。
- 难度仅取来源明确提供的 1–5 星。22 道国际菜没有难度标注，统一显示“无”。
- 缺失用时、份量、难度和材料用量显示“无”；“适量”“少许”等原文说明仍保留。
- 材料中的份数公式按原文保留，不自动计算配方。原文已量化的部分优先采用，补充原料表中遗漏的明确材料；工具和注释不作为材料。
- 删除 Markdown 样式和仓库 Issue/PR 征集结尾，不执行源文件中的任何内容；不导入开头的营养和保健功效宣传。
- 开源内容与译文未经团队逐道试做，未虚构审核、作者或营养参数。

## 应用接入

首页保持现有卡片布局与尺寸，精选展示 6 道；全部内容从“查看全部”、搜索和分类进入。分类补充主食、早餐、甜点、饮品、酱料、半成品、国际菜。搜索新增外文原名和风味标签，如输入 `miso` 或“日本”可找到日式味噌汤。

原来 12 道菜的 ID 保留，已有收藏和浏览记录仍指向对应菜谱，菜谱内容更新为来源原文。阅读页按菜谱版本保存临时位置，防止版本更新后错误沿用旧步骤索引。

## 更新与复现

需要 Python、Pillow 和首次源文件下载网络；普通 Android 构建无需 Python 或内容下载。

```powershell
python tools/import_catalog.py fetch
python tools/import_catalog.py build
python -m unittest discover -s tools/tests -v
```

固定仓库版本在导入脚本中。中文译文在 `tools/world_recipes_zh.json`，可通过 `tools/write_world_translations.py` 重建。缓存与详细导入报告写入忽略的 `artifacts/content-import/`；可提交的随包清单位于 `app/src/main/assets/catalog_sources.json`。

修改译文时应同时更新翻译输入生成器；修改导入规则后重新生成并运行菜谱包与 UI 测试。
