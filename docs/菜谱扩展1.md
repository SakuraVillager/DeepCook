# DeepCook 0.1.6：菜谱扩充与地域分类

## 内容

- 菜谱从 12 道扩充到 112 道：中式 52、日式 15、韩式 12、美式 10、欧式 10、东南亚 8、其他 5。
- 新菜谱按"检索公开资料 → 自编演示文字"的方式整理，文字未经独立试做验证；候选参考页只保留能直接访问的 11 个写入 `source.url`，其余留空，不展示打不开的链接，也不编造地址。
- 新菜谱暂未配图，`cover` 为空，界面显示占位图。最初 12 道的 HowToCook 配图、固定版本与来源清单不变。
- 内容格式升级到第 3 版；排版与既有 12 道统一：范围用破折号、数字与汉字之间留空格、正文以句号结尾。

## 数据与约定

- `Recipe` 新增 `region`（必填，取值：中式、日式、韩式、美式、欧式、东南亚、其他）。
- 分类只描述菜式：家常菜、快手菜、素食、肉类、海鲜、汤羹、主食、面食、烘焙甜点、早餐、沙拉。地域不写进分类，避免同一维度被记录两次；`RecipeCategoryOptions` = 全部 + 7 个地域 + 11 个菜式分类，供选择器使用。
- "无"占位：准备事项、注意事项、观察提示不适用时统一写"无"，界面隐藏该区块或该项（`Recipe.preparationItems`、`Recipe.noteItems`、`RecipeStep.visibleCue`），不渲染"观察提示：无"这类空行。数值字段缺失仍为空值，界面显示"—"，无障碍描述为"未标注"。
- 搜索：分类下拉把地域列在菜式分类之前；选中地域按 `region` 精确筛选，选中菜式按 `categories` 筛选；文本搜索同样匹配地域名（例如输入"韩式"）。

## 界面

- 卡片封面左上角增加地域徽标：surface 88% 不透明、8dp 圆角、11sp 文字，无障碍描述为"地域 X"。
- 列表行与详情复用 `RecipeMetadata`，在用时、难度之后追加地域项（公共图标），详情不额外占一行。
- 首页分类 chip 行改为 `RecipeCategoryOptions`，地域在前、菜式在后，可横向滚动；点击进入对应筛选的搜索页。
- 详情的分段索引改为按当前可见分段推算，不再假设"准备/注意"一定存在——此前硬编码的 item 下标在新增分段时会静默错位。

## 验证

- 新增 `tools/validate_content.py`：只读校验随包内容，覆盖 ID 唯一、地域/分类白名单、每道 3–6 步、材料 3–14 项、步骤 ID 与 `order`、材料引用、封面文件存在、地域分布、精选 6 道，以及"鲈鱼"唯一（UI 测试依赖）。
- 单元测试新增：地域筛选与菜式筛选并存、地域名文本搜索、选择器顺序、无占位隐藏、地域/分类白名单拒绝。
- Android 测试更新：总数、难度筛选与地域筛选计数按新内容重算，并新增地域徽标与地域筛选断言。
- 2026-10-17 实际构建通过：`:app:assembleDebug`、`:app:assemblePreview` 均成功，14 项 JVM 单元测试全部通过。产物 `artifacts/DeepCook-0.1.6-preview.apk`（3.3 MB，R8 优化，建议日常安装）与 `artifacts/DeepCook-0.1.6-debug.apk`（20.9 MB）。
- 未执行 `:app:lintDebug` 与 `:app:connectedDebugAndroidTest`（本机没有设备或模拟器）。工程位于含中文的路径，`:app:testDebugUnitTest` 的测试进程在该路径下无法启动；上述单元测试结果来自纯 ASCII 路径的副本。构建不受影响，`gradle.properties` 已设置 `android.overridePathCheck=true`。

## 交付

- Debug/Preview APK 需在具备 SDK 的环境构建；本版源码与内容已完成，版本号 `0.1.6`（versionCode 7）。
- 内容以 `app/src/main/assets/recipes.json` 为准；扩充内容由分批撰写后合并一次，后续增删改直接编辑该 JSON，并用 `tools/validate_content.py` 校验。
- 内容维护：`tools/prepare_content.py` 现在只重建最初 12 道，且要求 `DEEPCOOK_REBUILD_CONTENT=1`，避免误覆盖扩充内容。
