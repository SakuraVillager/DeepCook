# 菜谱组件与字号（0.3.3）

页面恢复暖黄厨房原有淡黄色底色。菜谱网格仍为双列自适应，图片保持 4:3，卡片圆角仍为 16dp。卡片与列表行使用白底、1dp 灰色边框；深色模式使用对应深色表面与边框。分类标签和图片底部元数据渐变移除，收藏按钮置于右上角，触控区域保持 48dp。

图片下方展示菜名、用时和五分制难度。已知用时统一使用 `min`，不换算成小时；未知参数继续显示“无”。搜索页改为返回、无边框输入区、清空操作同行，保留分类筛选、搜索规则与键盘搜索键。

## 参考截图测量

用户提供的两张原图均为 1080×2340，未包含可用于还原屏幕密度或字体缩放的元数据。按文字所在区域逐行统计深色像素，并合并字形笔画之间的空隙，得到以下近似墨迹高度。这些值不是字体框或行高，不能直接当作 sp。

| 区域 | 墨迹高度 |
|---|---:|
| 搜索栏中文 | 44px |
| 搜索列表中文 | 38–40px |
| 示例卡片英文菜名 | 40px |
| 卡片时间数字和单位 | 30px |

若按常见 360dp 逻辑宽度估算，1080px 对应约 3px/dp。考虑中英文字形占字体框比例不同，参考搜索和正文约为 16–18sp，整行大卡片标题约为 18–20sp，辅助信息约为 14sp。DeepCook 使用双列卡片，按可用宽度采用 16sp 菜名和 13sp 元数据；不复制参考图的单列布局。

## 应用字号

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 菜谱详情主标题 | 26 / 34sp | 半粗 |
| 我的厨房主标题、烹饪模式步骤标题 | 24 / 32sp | 中等 |
| 首页欢迎语与品牌 | 20 / 28sp | 中等 |
| 页面标题、内容分组标题 | 18 / 26sp | 中等 |
| 菜名、搜索输入、默认正文 | 16 / 24sp | 常规 |
| 设置项、个人页卡片标题 | 16 / 24sp | 中等 |
| 辅助说明、列表元数据 | 14 / 20sp | 常规 |
| 网格卡片元数据、次要说明 | 13 / 18sp | 常规 |

详情默认正文为 16sp，行高为字号的 1.5 倍；阅读偏好的大、特大字号仍生效。烹饪模式保留 24 / 28 / 32sp 大字正文。所有字号继续尊重系统字体缩放，并检查 1.0、1.3、2.0 倍及窄屏、宽屏布局。

## 页面覆盖

统一主题作用于所有页面和弹窗，页面内的字号按用途复核：

| 页面 | 字号层级 |
|---|---|

| 搜索 | 输入 16sp，菜名 16sp，结果数量和元数据 14sp |
| 菜谱详情 | 主标题 26sp，分组 18sp，材料和步骤正文默认 16sp，说明 14sp |
| 烹饪模式 | 顶栏菜名 16sp，步骤标题 24sp，正文按阅读设置 24–32sp |

| 外观、阅读、本地数据 | 页标题 18sp，设置项 16sp，分组和说明 14sp，确认弹窗标题 20sp |
| 来源、配图清单、开源许可 | 页标题 18sp，说明 14sp，较长清单 13sp |
| 关于 | 页标题 18sp，应用名 26sp，其他信息 14–16sp |
| 添加、编辑菜谱 | 页标题 18sp，区块和输入 16sp，字段标签 14sp，提示 13sp |
