# 0.3.0 云端与本地合并

目标云端分支为 `菜谱扩展1`，本地工作分支为 `菜谱扩展`。本次保留双方提交历史，不使用强制推送，也不改变 main。

## 合并范围

本地菜谱扩充已先独立提交为 `a313840`。云端功能基线为 `c5a29d8`，新增了地域分类、个人菜谱增改删、相册封面和 HowToCook 补全。

合并后包含 494 道内置菜谱：372 道 HowToCook 中文内容、22 道 Based Cooking 中文译文、100 道云端项目自编示例。219 道有配图。两个分支的菜谱 ID 均保留；同名不同来源的版本不强行视为同一配方。自编示例单独标识，未核实的总用时和难度留空。

地域不再默认“中式”：来源明确提及的地域或原有明确标签可以使用，其他为“无”。导入和验证不依赖固定地域配额，不限制真实菜谱必须只有 3–6 步、3–14 项材料或固定 version=3。

## 审查发现与处理

| 原问题 | 合并后处理 |
|---|---|
| 第一次补全覆盖手写字段 | 每次仅填空白，异步期间的修改保留；改名取消过期请求 |
| 已随包有完整资料仍必须联网 | 先查随包内容，缺失才尝试公开页面 |
| 默认填写中式、1 人份，错误沿用不确定元数据 | 默认未知，已知字段按来源填写；无值显示“无” |
| 保存协程未结束就返回 | 编辑器等待持久化成功；失败留在表单并可重试 |
| 更换或移除封面立即删除旧图 | 新图暂存，提交成功后清理旧图；放弃仅删暂存图 |
| 全景大图可能不采样，镜像方向缺失，编码结果未检查 | 限制解码尺寸/像素，支持全部 EXIF 方向，检查编码并清理失败文件 |
| 编辑丢来源、图片/步骤关联，新增行可能撞 ID | 保留来源与关联字段，保留旧 ID，分配未占用的新 ID，版本递增 |
| 草稿只在内存，返回总提示放弃 | SavedStateHandle 恢复草稿，按真实修改状态提示 |
| 用户数据损坏提示未显示，存储允许内置 ID 混入 | 可重试错误提示，拒绝非法个人内容，保留损坏文件 |
| 删除失败仍声称原数据完全不变 | 按实际提交顺序处理并提示操作未完成，不虚构跨文件原子事务 |
| 个人列表尾部按钮挤压菜名 | 编辑/删除放入管理菜单，保留收藏触控区域 |
| 校验器硬编码 112 道/地域计数/步骤数量 | 校验真实结构、来源、ID、引用和离线资源 |

网络回退仍保留，但请求固定版本、设置超时、限制响应大小且允许取消；没有 API Key、上传接口或后端。

## 可复现验证

```powershell
python tools/validate_content.py
python -m unittest discover -s tools/tests -v
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest
.\gradlew.bat :app:assemblePreview
```

Android 测试使用专用模拟器，未操作用户物理设备。Preview 开启 R8 和资源缩减，使用现有开发签名，可以覆盖同签名旧版；正式商店发布签名另行配置。

来源记录在 `catalog_sources.json`，示例图片的额外授权记录在 `photo_sources.json`。导入器、固定源文件版本、中文翻译输入和云端示例输入均保留。`docs/菜谱扩充说明.md`、`docs/菜谱扩展1.md` 等旧数量文档记录各分支合并前的历史，不代替此说明。

## 最终验证记录（2026-10-17）

51 项 JVM 测试、16 项 Android 15 模拟器测试、7 项 Python 导入器测试全部通过。真实内容校验覆盖 494 道菜谱、219 张对应配图和 372 项后备索引。Debug、开启 R8 的 Preview 构建成功，Kotlin 格式检查及 Git 空白检查通过。Android Lint 无错误，剩余 7 项仅为既定 SDK 36 和依赖版本的更新提示，本次未扩大范围升级工具链。

优化版检查了个人中心、个人菜谱管理、离线补全，以及系统字体 2 倍下的编辑页。安装包为 `artifacts/DeepCook-0.3.0-preview.apk`；开发调试包另存为 `artifacts/DeepCook-0.3.0-debug.apk`。
